## Tiempo sugerido

- **Duración estimada:** 2 semanas.
- **Ritmo recomendado:** 5 a 7 horas por semana distribuidas en 3 o 4 sesiones.

## Temas Principales

<details>
<summary><strong>1. ¿Cómo funciona Java?</strong></summary>
Compilación vs Interpretación. Bytecode. El rol de la JVM (Java Virtual Machine) y por qué hace a Java 'Write Once, Run Anywhere'.
</details>

<details>
<summary><strong>2. Instalación del Entorno</strong></summary>
Instalar OpenJDK (versión 21 LTS recomendada). Configurar variables de entorno (JAVA_HOME, PATH). Instalación de IntelliJ IDEA Community (el estándar de la industria).
</details>

<details>
<summary><strong>3. Pensamiento Algorítmico (CRUCIAL)</strong></summary>
Variables, constantes, secuencias, decisiones y bucles en papel. No te saltes esto. Si no puedes resolverlo en papel, no podrás programarlo.
</details>

---

## Criterios de salida

- Puedes explicar con tus palabras la diferencia entre **JDK, JRE y JVM**.
- Tienes un entorno funcional y verificas Java desde terminal (`java -version`, `javac -version`).
- Puedes compilar y ejecutar un `HelloWorld.java` sin depender del IDE.
- Sabes traducir un problema cotidiano a pasos lógicos (pseudocódigo o flujo).

## Autoevaluación rápida

1. ¿Cuál es la diferencia práctica entre JDK y JRE?
2. ¿Qué ocurre entre `javac Archivo.java` y `java Archivo`?
3. ¿Qué variables de entorno suelen configurarse y para qué?
4. Describe en 5 pasos cómo resolverías un problema antes de programar.
5. ¿Qué error te apareció al ejecutar Java y cómo lo resolviste?
