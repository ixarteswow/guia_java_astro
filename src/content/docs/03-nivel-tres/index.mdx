## Temas Principales

<details>
<summary><strong>1. Manejo de Excepciones (CRUCIAL)</strong></summary>
Try-Catch-Finally. Checked vs Unchecked Exceptions. Crear excepciones personalizadas. Try-with-resources.
</details>

<details>
<summary><strong>2. Collections Framework (CRUCIAL)</strong></summary>
List (ArrayList vs LinkedList), Set (HashSet, TreeSet), Map (HashMap, TreeMap). ¿Cuándo usar cuál? Complejidad Big O básica.
</details>

<details>
<summary><strong>3. Generics</strong></summary>
Seguridad de tipos. `<T>`, `? extends`, `? super`. Evitar ClassCastException en runtime.
</details>

<details>
<summary><strong>4. File I/O (NIO.2)</strong></summary>
Leer y escribir archivos. Path, Files. Manejo de streams de datos.
</details>
