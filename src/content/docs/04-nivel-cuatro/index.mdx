## Objetivos de la Fase

*   ✅ Programación Funcional (Lambdas, Streams).
*   ✅ Uso de Optional para evitar NullPointerException.
*   ✅ Características nuevas: Records, Switch Expressions, Var.

## Temas Principales

<details>
<summary><strong>1. Lambdas e Interfaces Funcionales (CRUCIAL)</strong></summary>
Sintaxis de flecha `->`. Interfaces Predicate, Consumer, Supplier, Function. `@FunctionalInterface`.
</details>

<details>
<summary><strong>2. Stream API (CRUCIAL)</strong></summary>
Operaciones intermedias (filter, map, sorted) y terminales (collect, reduce, forEach). Procesamiento declarativo de colecciones.
</details>

<details>
<summary><strong>3. Optional (CRUCIAL)</strong></summary>
El fin de `if (obj != null)`. Métodos `orElse`, `ifPresent`, `map`.
</details>

<details>
<summary><strong>4. Novedades Java 14-21</strong></summary>
Records (DTOs inmutables en 1 línea), Pattern Matching para instanceof, Text Blocks.
</details>
