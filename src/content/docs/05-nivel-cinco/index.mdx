## Temas Principales

<details>
<summary><strong>1. Build Tools (Maven/Gradle) (CRUCIAL)</strong></summary>
Estructura de proyecto estándar. Archivo `pom.xml` o `build.gradle`. Gestión de librerías externas.
</details>

<details>
<summary><strong>2. Unit Testing (JUnit 5) (CRUCIAL)</strong></summary>
Aserciones (`assertEquals`). Ciclo de vida (`@BeforeEach`). Test Driven Development (TDD) básico.
</details>

<details>
<summary><strong>3. Git & GitHub (CRUCIAL)</strong></summary>
Commit, Push, Pull, Branching básico. Subir tu portafolio.
</details>
