## Prerrequisitos

- Haber completado N3, N4 y N5.
- Manejo básico de Git y testing unitario.

## Outcomes (lo que debes lograr)

- Diseñar y exponer una API REST con Spring Boot.
- Persistir datos con PostgreSQL y JPA.
- Implementar tests de integración y manejo de errores consistente.
- Desplegar un servicio básico y documentar su operación.

## Ruta sugerida (8 semanas)

1. Spring Boot básico + capas (`controller`, `service`, `repository`).
2. Persistencia con JPA/Hibernate y migraciones.
3. Seguridad inicial (JWT o sesión) + validación de inputs.
4. Testing de integración (Testcontainers opcional).
5. Observabilidad mínima (logs estructurados + health checks).

## Proyecto final del track

Construye una API de gestión de tareas multiusuario con autenticación, filtros avanzados y documentación OpenAPI.
