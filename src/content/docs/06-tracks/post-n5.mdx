## Objetivo

Pasar de nivel formativo a **perfil empleable** con evidencia técnica pública (portfolio + repos + documentación).

## Plan de 90 días

### Días 1–30: Base productiva
- Elegir 1 track principal.
- Definir proyecto portfolio con alcance y criterios de éxito.
- Publicar primera versión funcional con README y tests.

### Días 31–60: Profundidad
- Añadir una capacidad avanzada (seguridad, performance o diseño).
- Incorporar pruebas más sólidas (integración o carga básica).
- Documentar decisiones técnicas y trade-offs.

### Días 61–90: Empleabilidad
- Simular entrevistas técnicas semanales.
- Refinar CV/LinkedIn/GitHub con evidencia de impacto.
- Preparar demo de 10 minutos de tu proyecto principal.

## Entregables mínimos

- 1 proyecto principal terminado.
- 1 proyecto secundario breve.
- README profesional + changelog + arquitectura explicada.
